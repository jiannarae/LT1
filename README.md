# Circular Garden

## Description
This code asks the user for the radius, then calculates the area, circumference, square root, and the area rounded down and rounded up to the nearest whole number

## How to Run
1. Open the program file in PyCharm
2. Run the program
3. Enter the value for the radius in meters
4. Check the area, circumference, square root, and the area rounded up and rounded down to the nearest whole number

## Input Needed
- radius in meters

## Sample Output
Enter radius in meters: 5
Area of the Garden: 78.54 square meters
Circumference of the garden: 31.42 meters
Square root of the area: 8.86
Area rounded down: 78 square meters
Area rounded up: 79 square meters
